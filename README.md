# 留白 / Blank

比亚迪 DiLink 车机的第三方桌面。实测车型:护卫舰 07(DiLink 4.0,Android 10)。

> 本项目与比亚迪无关,不是官方产品。车控功能通过 ADB shell 级权限调用车机系统服务实现,
> 请自行判断风险;行车中请勿操作屏幕。

## 功能

- **桌面**:壁纸 + 自由摆放的卡片(车控、时间、游戏中心)+ 两个画中画位(地图、音乐等常驻应用就地运行)
- **常驻 Dock 与顶栏**:盖在原厂导航栏/状态栏的位置上,任何页面都在;Dock 上直接调空调温度、风量、座椅
- **空调面板**:温度、风量、出风模式、座椅加热/通风
- **外观**:内置 / 我的(U 盘或本地目录)/ 在线壁纸,支持图片、视频和网页壁纸;浅色、深色配色和强调色
- **游戏中心**:红白机、街机、GBA,在线游戏库按需下载,手机扫码当手柄,存档与金手指
- **浏览器**、**应用抽屉**、**检查更新**(查本仓库的 GitHub Releases)

## 提权

车控、画中画、Dock 常驻这些需要 ADB shell 级权限。两条路任选:

1. **内置**:打开车机的无线调试,留白开机自己连本机 ADB(首次在车机上点「允许」)
2. **Shizuku**:装 Shizuku 并激活后,在留白里授权

没有提权也能当普通桌面用,对应功能会提示「需提权」。

## 编译

需要 **JDK 17** 和 **NDK 28.2.13676358**(游戏中心有原生代码),缺一样都编不过,而且报错不指向真正原因。

```bash
sdkmanager --install "ndk;28.2.13676358"
JAVA_HOME=/path/to/jdk-17 ./gradlew assembleDebug     # 或 assembleRelease
```

判断编译结果只看 `BUILD SUCCESSFUL`,别把输出接 `| tail`(会吞掉失败的退出码)。

release 签名可选:按 `keystore.properties.example` 建一份 `keystore.properties`,
不建就用 debug 签名,自己装车够用。

版本号 `versionCode` = git 提交数。发版时 GitHub Release 的 tag 末尾数字要等于它(如 `v1.0.123`),
并附上 `.apk`,车机上的「检查更新」才认得出。

## 安装

用 U 盘或 `adb install` 装。车机自带的安装器拒装「桌面类应用」,所以桌面入口在安装时是关着的,
首次打开留白后自动启用,再在系统里把留白设为默认桌面即可。

## 离车调试

`tools/car-avd.sh up` 起一个 1920×1080 / API 29 的模拟器并拉起 Shizuku(幂等,日常就用它)。
没有真车时空调等车控走 mock 数据。

## 在线内容

留白自己不运营任何服务器,在线内容都由车机直连第三方:

- **在线壁纸**:Dynamic Wallpaper(macOS 应用)公开 CDN 上的视频。清单和视频都从它那儿取,
  客户端只挑车机放得了的(≤1080p)
- **在线游戏库**:yikm.net 的列表和 ROM
- **游戏核心**:随包附带;缺的从 libretro 官方 buildbot 下

这些内容的版权归各自权利人所有,本项目不对其可用性和合法性作任何保证。BIOS 不随包提供,
需要的游戏(NeoGeo、PGM 等)请自行放到游戏目录。
